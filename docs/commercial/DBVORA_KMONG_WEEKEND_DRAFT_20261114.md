## 상품 단위 기준 — 단일 DBVORA 상품 + 후속 옵션 확장
개별 엔진마다 다른 상품을 중복 등록하지 않는다. **DBVORA 단일 상품**으로 시작할 수 있는지 검토하고, 미래 확장 요소는 명시적으로 '향후 검증 완료 시 추가 예정'에 한정한다. 미래 기능 구매권/현재 제공 기능으로 표시하지 않는다. 이력은 등록 후에도 절대 삭제하지 않고 실제 등록 증빙 확인 후 중앙 '등록완료'로 변경한다.

### 상품 제목(승인 전 제안)
**DBVORA | SQLite·PostgreSQL 데이터베이스 구조 시각화·백업 검증 프로그램**

대체 제목: **로컬에서 확인하는 데이터베이스 구조맵·SQLite 안전 백업/복원 도구 DBVORA**

추천 카테고리: IT·프로그래밍 → 데이터베이스 (실제 등록 화면에서 카테고리 적합성 최종 확인).

### 사용자에게 설명할 핵심 가치
- 고객이 허가한 SQLite DB 또는 별도로 허가된 PostgreSQL 메타데이터를 **읽기 전용**으로 탐색하고 테이블·컬럼·키·FK 등 관계를 시각화한다.
- SQLite는 원본과 별도 위치에서 ZIP/ZSTD(설치된 별도 실행기 필요) 스냅샷·무결성 확인·새 폴더 독립 복원 기능을 제공한다. **고객 DB를 자동 수정·튜닝·삭제하지 않는다.**
- 데이터는 기본적으로 로컬에서 처리하며, 소유자의 명시적 네트워크 승인 없이 원격 PostgreSQL 접속을 시작하지 않는다.
- 별도 구매자 환경에 따른 Python3.11+ / 브라우저·필요 라이브러리·zstd 조건과 지원 OS는 실제 현장 테스트 결과에 맞춰 표시한다. EXE/설치형, 암호화/서명, 전원차단 복구 보증을 함부로 광고하지 않는다.
- 저장 최적화는 **측정된 실제 수치만** 사용한다. ZIP보다 무조건 압축률이 높다, Supabase보다 항상 저렴하다 같은 주장은 금지한다.

### 상품 설명 원고(출시 전 수정 필요)
**복잡한 DB 구조, 파일을 직접 수정하지 않고 확인하세요.**

DBVORA는 사용자가 승인한 데이터베이스의 테이블·컬럼·기본키·외래키·인덱스·관측 가능한 저장 지표를 로컬에서 확인하는 개발자용 도구입니다. SQLite는 승인된 원본을 별도 경로로 스냅샷·압축하고, SHA-256과 SQLite 무결성 검사를 통해 복원 결과를 독립 검증하도록 설계됐습니다. PostgreSQL 지원은 별도의 읽기 전용 TLS 조건에 한정하며 실제 구매자 환경 지원은 출시 검증 후 확정합니다.

개발/관리자가 직접 보면서 판단하는 **읽기 전용 구조 관제와 수동 검토 도구**로, 자동 쿼리 튜닝·DB 변경·서버 장애 복구 대행과는 다른 상품입니다.

## 대표 이미지/설명 구성 — 실제 검증 캡처로만
1. 표지: DBVORA 로고 + “DB 구조 파악 / 읽기 전용 / 로컬 실행” (보안 인증·판매 승인 인장 금지).
2. 실제 합성 DB 구조맵 캡처(테이블, FK, 저장량 출처 구분).
3. SQLite ZIP→신규 디렉터리 독립 복원 SHA 일치의 **실제** 사용자 Windows 캡처.
4. STANDARD/DELUXE/PREMIUM 비교와 필요한 고객 PC 환경.
5. 지원/제외·사전 요구·개인정보·환불/문의/수정 범위 안내.

## 주문 전/납품 확인 조건
- 타인의 실고객 DB/로그/접속 키 수집 금지. 서비스가 필요한 경우 합성 DB 또는 고객이 공유를 허가한 스키마 추출물 우선.
- 기술 지원 범위, 라이선스(1인/1PC/상업 이용/재판매 금지 등), 업데이트 및 환불/수정 기준은 **판매자 최종 승인 필요**.
- 설치형 EXE가 아니라 Python이 필요한 개발자용 포터블 소스라면 이 제약을 제목/설명에 분명히 표기.
- 공급 원본 SHA/독립 테스트/변조 거부·정확한 NOTICE/LICENSE·사용자 Win11 환경/PG TLS 수용 확인.
- 신규 상품 등록 버튼은 사용자가 주말에 최종 확인하고 직접 실행한다. 실제 등록 증빙 없이 '등록완료' 절대 표시하지 않는다.
