## 후보 1. BID AX — 나라장터 등 공공입찰 준비 자동화
- 출발점: 신규 상품 기획. 기존 HAE, Lightning Azent, EAI의 검수·워크플로 원리를 라이선스와 실제 API 계약 확인 후 참고할 수 있다.
- 고객: 공공 조달 입찰 담당자, 소규모 업체.
- 무료 대안 대비 구매 이유: 기업 프로필·면허·지역·예산 조건으로 공고 선별, 제출 자격·필수서류·만료일 체크리스트, 변경·마감 추적, 공고 원문 근거가 있는 보고서.
- 정확한 결과 표시: 적합 / 부적합 / 추가 확인 필요. 입찰 자격 충족을 법적으로 보장하지 않는다.
- 가설 가격: BASIC 39,000원(검색·필터·내보내기) / STANDARD 99,000원(기업 프로필·서류 검수·마감·PDF) / PREMIUM 179,000원(다중 기업·변경 이력·고급 보고).
- 설계 A 중앙 호스팅/SaaS: 서버·API 키/권한·상시 운영비·고객정보 위험 높음.
- 설계 B 우선안: Windows 로컬 설치 + 고객 본인 공식 공공데이터 키 + SQLite + PC 실행 중 로컬 알림. 고객별 API 한도 및 정책 최신 확인 필요. 공용 API 키를 EXE에 포함하지 않는다.
- 구현 전제: 공식 조달 API의 상업적 이용 조건·한도·기간 검색·데이터 변경 확인, 재시도/중복 방지, 실제 규칙 근거, 고객 PC 백업/복구, 개인정보·키 보호, Windows EXE, 사용 안내.
- 출시 게이트: 실제 공고 100건 수집/변경/오류 재현과 10건 이상 자격·서류 대조, 원문 근거·사람 최종 확인, 설치/제거·고객 시나리오·상업 이용권 확인. 현재 모두 NOT RUN.

## 후보 2. FlowPilot Universal — PC·USB·SMB 파일 납품 검수
- 출발점: UGREEN 저장소 hibi89/hibi89-ugreen-nas-hackathon, lead/ugreen 브랜치의 ProjectReady 파일 체크·버전 충돌·보안 정책·근거 로직. 실제 Windows/SMB 스캐너가 준비됐다고 주장하지 않는다.
- 고객: 영상/디자인/개발 납품자, 프로젝트·자료 관리 업무 담당자.
- 무료 대안 대비 구매 이유: 체크리스트 기반 필수 파일 누락, 중복/버전 충돌 후보, SHA256 무결성, 원본 보존·읽기 전용 스캔, 검수 HTML/PDF 증빙과 반복 검수.
- 가설 가격: BASIC 39,000원(로컬 파일 누락·중복) / STANDARD 79,000원(템플릿·버전·SHA·보고서) / PREMIUM 149,000원(권한 있는 SMB 공유폴더·대량 처리·검사 이력).
- 설계 A 공식 UGREEN Uliya Skill 의존: 타 제조사·일반 PC 지원 범위 좁고 실 NAS 검증 미완.
- 설계 B 우선안: 별도 로컬 파일시스템 스캐너 + OS가 노출한 SMB 공유폴더 + 기존 검수 계약. NAS 자동관리나 임의 실행을 포함하지 않는다.
- 구현 전제: 경로 이탈·심볼릭 링크·권한 실패/부분조회, 원본 수정 차단, 대용량/중단/재개, 한글·장기 파일명, 동시 변경·증거 신뢰성, Windows 설치·백업·복원.
- 출시 게이트: PC/USB/외장장치 및 서로 다른 제조사의 실제 SMB NAS 공유폴더에서 권한 있는 READ 시험, 납품 보고서 실제 비교, 고객형 3회 이상 검수·상업권 확인. 현재 범용판 NOT BUILT/NOT RUN.
- 표현 금지: 모든 NAS 100% 자동 호환, UGREEN 실기기 검증, 검수 없이 개인정보 안전 확정.

- 설계 B 우선안: 기존 견적/승인/마일스톤 원장만 추출해 한국 원화/부가세·문서 출력·로컬 SQLite/Windows UI로 독립 상품화. PayPal 거래와 유료 AI는 필수 기능에서 제외.

- 출시 게이트: 실제 업종별 샘플 10건 이상, 문서/한글 폰트/회계 및 상태 계산, 데이터 복구, Windows 고객 사용성/라이선스, 판매 승인. 현재 독립판 NOT BUILT/NOT RUN.
