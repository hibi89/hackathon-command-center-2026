# ChatGPT 웹·Codex 글로벌 사용자지침 충돌 해소 — 사용자 수동 적용 요구
2026-11-16 KST / OWNER-DEV-EXECUTION-V2

## 제약
연결된 GitHub 도구는 저장소/브랜치의 `AGENTS.md`를 편집할 수 있지만, ChatGPT 계정의 **글로벌 사용자 지정 지침(Custom Instructions)** 또는 Codex 계정/로컬의 **전역 지침**을 직접 읽거나 수정할 수 없다. 기존 내용을 자동으로 지웠거나 교체했다고 보고하지 않는다. 따라서 아래 구형 실행 문구가 실제 설정에 있다면 사용자 본인이 해당 설정에서 수정해야 한다. 변경 전 원문을 로컬에 백업한다.

## ChatGPT 웹 사용자지침: 기존 충돌 문구 대체
이전 '고추론 GPT가 설계·코딩·수정·테스트·검수를 직접 전담' 및 '매 작업마다 전체 CI 확인'이라는 취지의 일반 규칙을 다음으로 대체:

> **최신 공통 제품 개발 원칙(2026-11-16):** 최초 최종설계·아키텍처·모든 요구사항의 구현가능 작업 큐와 수용기준은 **웹 GPT-6 Sol High**가 고정한다. 합의된 설계에 대한 **백엔드·프론트엔드 주력 구현은 웹 GPT-6 Sol Instant**가 수행한다. 각 `ㄱ`에서 가능한 독립 READY 티켓을 여러 개 실제 코딩·GitHub 커밋하고, 고난도 구조 변경·고위험 보안/DB/권한·반복 실패만 High에게 넘긴다. 구현 100% 후보가 되면 전체 CI·통합·기능·보안·실기기 검증을 묶어 실행하고 수정한다. 중간에는 위험 변경의 필수 안전검사와 기존 CI 보호 규칙을 유지한다. **Codex GPT-6.1 Sol Max**는 독립 기술·보안 검수, **Astra Max**는 독립 UI·UX 검수, **웹 Sol High**는 최종 결과 인수, **Codex Luna Extra High**는 사용자 출시 승인 후 크몽 게시를 담당한다. 모델을 실제로 선택할 수 없는 경우 해당 역할은 보류·미검증으로 표시한다. 원본·사용자 확정 최종설계/공식률·고객권리·비밀·보안·출시 승인 규칙은 보존한다. 새 채팅은 먼저 제품 repo/branch/HEAD와 `AGENTS.md` 최신 지침 확인→`HANDOFF/STATUS/REQUIREMENTS/최종설계/실소스/Instant 큐` 순으로 검증한다. HANDOFF 이력의 구형 실행 지시가 최신 정책을 덮지 못한다.

## Codex 전역 사용자지침: 반영 문구
기존 'Codex가 일반 구현 주담당', 'Codex가 개발 중간 UI 구현', '아직 구현되지 않은 설계를 독립 검수 완료로 처리' 취지의 문구가 있다면 아래로 대체:

> **Codex 최신 역할:** 웹 Sol High가 최초 설계, 웹 Sol Instant가 주력 구현을 담당한다. Codex는 사용자 지정한 **GPT-6.1 Sol Max 기술·보안 독립검수**, **Astra Max UI·UX 독립검수**, **Luna Extra High 최종 크몽 상품화/승인 후 등록**을 우선 맡는다. 명시적인 Codex 코드 구현 위임이 있는 경우에만 별도 파일 소유권/브랜치에서 구현한다. 실제 repo/branch/HEAD와 `AGENTS.md` 최신 정책→최종설계/수용기준→정확 SHA/변경 소스/검증 결과를 읽고, BLOCKER/HIGH 재현 근거를 남긴다. 개발 미완료는 합격으로 표시하지 않는다. 기존 원본/보안·고객권리·사용자 승인·게시 증거 조건을 준수한다. 계정/유료 API/권한·배포·판매를 임의 변경하지 않는다.

## 사용자 개입
1. ChatGPT 웹의 설정에서 사용자 지정 지침(또는 개인화된 지침) 내용을 확인한 뒤, **충돌하는 개발 역할/검증 순서 구절만** 위의 웹용 문구로 교체. 기존 보안·원본·완성률·GitHub 정책은 그대로 둔다.
2. Codex의 전역 사용자지침/프로필 지침과, 로컬 Codex CLI를 사용하는 경우 해당 전역 `AGENTS.md` 또는 관련 설정을 확인해 충돌 구절만 위의 Codex용 문구로 교체. **GitHub 저장소별 AGENTS.md는 별도로 이번 배포를 진행했음**.
3. 변경 후 새 채팅/새 Codex 작업에서 `역할→정본 repo/branch→최신 AGENTS→HANDOFF/STATUS→설계/소스`가 적용되는지 짧게 확인. 개인 계정 설정은 이 저장소가 자동 확인할 수 없음.

## 적용 판정
- GitHub 레포별 정책 = 실제 커밋과 readback 후 `APPLIED`.
- ChatGPT 웹 전역 지침 = `OWNER_ACTION_REQUIRED / NOT_VERIFIED`.
- Codex 계정/로컬 전역 지침 = `OWNER_ACTION_REQUIRED / NOT_VERIFIED`.
- 실제 현재 Plus/Pro 사용량과 2026-12월 개편은 계정에서 직접 확인 필요. 사용량 우대를 보장하지 않음.
