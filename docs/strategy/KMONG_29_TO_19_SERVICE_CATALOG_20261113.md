## 크몽 등록 이력 영구 보존 · 중복 방지 정본 (2026-11-13 사용자 확정)

- **등록을 마친 서비스도 이 1~19위 원본 목록에서 절대 삭제하지 않는다.** 실제 크몽 등록·심사 완료가 확인된 경우에만 기존 행의 상태를 **등록완료**로 바꾸고, 서비스 ID·등록 URL·등록일(KST)·증빙·변경 이력을 남긴다. 임의로 등록완료를 추정하지 않는다. 현재 실제 등록 증거가 없어 19개는 모두 **미등록**이다.
- 상태는 **미등록 → 심사중 → 등록완료** 순으로 관리하되, 판매중지·비공개·삭제된 경우에도 **이전 등록완료 사실과 과거 URL/이력을 지우지 않고** 현재 상태 및 변경 사유를 추가한다. **등록완료는 개발완료/P95/P100/판매 승인과 별개**다.
- 새 상품을 기획·결합·등록하기 전에 전체 **등록완료·미등록·판매중지 이력 및 원천 29종/하위 모듈 매핑을 검색**한다. 동일 고객 문제·납품 결과·기술 구성인 경우 신규 게시를 자동 결정하지 않고 기존 게시의 STANDARD/DELUXE/PREMIUM 옵션/추가 메뉴로 통합 가능한지 먼저 검토한다. 실제로 독립 고객 요구가 있을 때만 새 고유 ID의 별도 상품 후보를 추가한다.
- **기계 판독 정본:** [service catalog JSON](../../data/kmong_service_catalog_20261113.json) 각 ranked service의 `service_id`, `listing_status`, `kmong_listing_url`, `published_at_kst`, `listing_history`. 등록 증거 없으면 `listing_status: "미등록"`, URL/날짜 `null`, 이력 빈 배열을 유지하며 실제 등록에 따른 수정은 기존 이력의 보존을 전제로 한다. 우선순위는 이동할 수 있어도 ID와 과거 이력은 유지한다.

## 경계: 소스가 같다고 모두 합치면 안 됨

- **PREP↔SMAX²**: 동일 고객 데이터 정제·매핑 → 하나의 게시글/고급 옵션. **AI AutoML Analyst↔ONTOINSIGHT AX**: 분석/의미관계 심화. **RAG Studio↔CITEVAULT**: 개인 지식검색→기업형. **AI Code Checker↔REA_APP↔PROOFQA**: 정적코드→소스 구조→승인된 브라우저/보안 인수검수.
- **HAE↔Lightning Azent↔AZENTFLOW**: 자동화 설계 UI·실행기·기업 납품을 단계 확장. LA 실행기 정본/권한은 별도 보존. **REA_Web↔SITECRAFT**: 허가 사이트의 관찰→독립 재구축→기업 납품. **코인 수집기↔패턴 분석기**: 데이터 수집→통계 분석.
- **SOVIA는 독립 감사 제품 원설계**이므로 HAE PREMIUM의 선택 모듈로 재사용할 수 있어도 완전히 흡수/종료하지 않으며, 독립 감사 목적의 별도 판매 서비스 후보를 유지한다. **FFAX**는 React 제작·UI 코딩 도구로 REA_Web 사이트 분석/재구축과 구매 목적이 달라 분리. **EAI**는 검증형 범용 로컬 목표 엔진으로 예측/통계 보고 중심 AutoML과 분리. **REA_APP은 Python/JS/TS 소스 분석기**이므로 이름이 비슷한 REA_Web이나 DATA2WEB에 통합하면 잘못이다.
- **DBVORA**는 DB 진단, RAG는 지식검색, PREP는 파일 전처리, DATA2WEB은 웹 보고서 생성으로 각각 다른 산출물. **Factory AX**는 제조기업 LOT/발주/검사/출하와 현장 검수/설치·인수라는 별도 고객 계약으로, 범용 데이터 정제와 같은 범위를 이름만 바꿔 중복 등록하지 않는다.
- **AXMART³ CUBE**는 판매자가 보유한 카탈로그/유통 인프라이지 고객에게 납품하는 스토어 빌더 상품이 아님. 제3자 고객용 스토어 제작 제품으로 만들려면 별도 확정 설계·고객/계정/결제/환불·보안/운영 검증 및 승인 후 재분류.
- 기존 SKU를 묶어도 **GitHub 저장소/브랜치·최종설계 100% 범위·원본 코드·데이터·인증·[작업중]·[사용자 개입 필요]·실완성률** 절대로 덮어쓰지 않는다. 하위 고급 기능이 새로운 독립 결합 제품이면 자체 추가 통합 수용 테스트 없이는 **구현/P95 판정 불가**.
- 크몽의 **STANDARD/DELUXE/PREMIUM**은 공개 실제 상품에서 쓰이는 판매 패키지 형식이다. **3등급이 3개 크몽 게시글은 아님**. 동일 내용·조건으로 별개 게시글을 늘리는 방식 지양. 크몽 계정당 서비스 개수·심사·옵션 카테고리 기준은 해당 판매자 계정에서 추가 확인 필요.
