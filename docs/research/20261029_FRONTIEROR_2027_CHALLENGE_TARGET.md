# 2027 FrontierOR Challenge — 개인 소버린 AI 실전 검증 목표

> OWNER INTENT / 2026-10-29 KST. **도전 목표/연구 백로그 등록만 완료. 참가 등록·개발 착수·대회 통과·실측 성능을 뜻하지 않는다.**

## 기록할 핵심 사용자 결정
- 2027-01-04 시작하는 **FrontierOR Challenge 2027**을 자체 **독립형 로컬 소버린 AI**의 첫 OR 실전 검증 목표로 설정.
- 기존 **REA_AI = 기존 AI 기술의 역공학·작동 원리 분석/재구성**. 이번 소버린 AI는 **별도 무명 프로젝트**이며 REA_AI로 부르지 않는다.
- 선행: 현재 2026 KIC, PayPal, UGREEN 해커톤의 제출 목표를 보존하고, **LA 워크플로/실행 검증이 먼저**. 이후 GPU 로컬 LLM + CPU 탐색·검증 + ML 피드백 아키텍처를 단계별 실험.
- 11월 LA 안정화 → 12월 초 최소 end-to-end → 12월 중 공식 연습 6종에서 유효한 해 생성 목표 → 12월 말 2 vCPU/4 GB 오프라인 환경 측정 → 2027-01-04 예선 1라운드 도전.
- **내부 검증**: (1) 유효한 해 (2) 해의 품질·CPU 시간·메모리·총비용에서 기존 솔버 대비 실제 개선 (3) 공식 제출 계약 통과. **예선 합격**은 공식 발표로만 판단.
- 공식 예선은 2027-01-04~02-01 **4주 60문제**를 누적 점수로 평가하며, 60문제 전부 푼다고 자동 통과하지 않는다. **결선 진출 팀 수/커트라인 미확정**.
- Main: 독립 Python solver, 2 vCPU/4 GB/네트워크 차단, 공개 라이선스 의존성. 별도 Self-hosted 방식은 자체 장비 기반. 제출 트랙·등록 여부는 공식 규정과 사용자 결정을 따름.
- 이 문서는 단지 **대회/연구 목표**를 기록할 뿐 새 저장소, 코드, 제출, 계정, 유료 API/서버를 자동 승인하지 않는다.
