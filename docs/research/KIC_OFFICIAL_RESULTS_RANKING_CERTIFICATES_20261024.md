## 통합 포트폴리오 기록 규칙 — 세 대회 공통 원칙

1. **참가 등록 ≠ 유효한 공식 제출.** 제출 탭의 최종 상태/영수증이 있어야 '공식 제출'로 기재.
2. **제출 ≠ 본선 진출 ≠ 입상/수상 ≠ 전체 참가자 공식 등수.** 각각 별도 공식 URL과 계정/팀 연결 증거 필요.
3. 등수를 인용하려면 **공식 순위 URL, 실제 순위, 유효 참가팀 총수, 동점/실격 처리와 게시 날짜**를 함께 저장. 분모 없으면 '상위 n%'를 임의 계산하지 않음.
4. 인증서는 실제 발급된 원본/식별정보·적용 대회·발급일이 있을 때만 기재. 일반 규정에 있다거나 참가만 했다고 취득으로 표시하지 않음.
5. **프로젝트 완성 근거는 별도:** GitHub 소스·기술 설계·CI와 코드 SHA·데모 URL·자기 기여 범위/AI 사용 설명·실제 API E2E 인증 범위. Test PASS 수치는 심사 순위가 아님.
6. 포트폴리오에 개인정보가 포함된 계정·접수·인증서 **원본을 Public GitHub에 업로드하지 말 것**. 대외 공개는 사용자 승인 후 식별정보를 가리거나 공식 공개 URL 활용.
7. PayPal·UGREEN은 **각각 자체 공식 대회 규정에서 결과 공개/순위/인증서 제공 여부를 별도 검증**할 것. KIC 결과나 DACON 일반 규칙을 세 대회 공통 확정 규정으로 일괄 적용 금지.
