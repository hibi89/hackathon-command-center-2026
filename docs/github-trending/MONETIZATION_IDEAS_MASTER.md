## 3. 주요 3종 상세 상품화 가설 (주문·판매 보장 아님)

### TOP1 — WEB-01 웹사이트 점검
- **고객**: 쇼핑몰·홈페이지 제작 업체. **납품**: URL 입력, 허가된 폼/버튼 시나리오, 브라우저 동작 증거, 실패 스크린샷, HTML 리포트, Windows 설치 가이드.
- **가격·기간 추정**: 7만~30만원, MVP 2~8시간, 상품화 1~4일, 중급. 테스트 시나리오가 정해진 고객에 유리.
- **차별화**: 단순 AI 점검 주장이 아니라 재현 가능한 실패 근거와 재검수, 별도 AI 구독 없이 기본 로컬 실행. **제약**: 브라우저·버전·사이트 권한·시크릿 마스킹, Agent Browser와 Chrome 가이드의 실제 재배포 의무 확인.

### TOP2 — WEB-02 수집·정리
- **고객**: 온라인 판매자·시장조사 담당자. **납품**: 허용된 공개 페이지 수집, 중복 처리, CSV/Excel, 작업 로그, 실패 재시도 옵션.
- **가격·기간 추정**: 7만~35만원, MVP 2~4시간, 상품화 1~2일, 중급. **차별화**: 사이트별 규칙에 맞춘 설정+사후 오류 확인.
- **제약**: 사이트 약관·robots·저작권·개인정보·API 제공자 권리. Scrapling의 과거 보고상 BSD-3-Clause는 **판매 전 직접 재확인**.

### TOP3 — DEV-02 AI 개발환경 검수
- **고객**: AI 코딩 사용자·개발 프리랜서. **납품**: 사양서 템플릿·스킬 설정·테스트 명령·리뷰 체크리스트·근거 로그.
- **가격·기간 추정**: 5만~25만원, MVP 2~6시간, 상품화 1~3일, 하~중. **차별화**: '프롬프트 모음'이 아니라 실행 가능한 검수 절차·검증 결과.
- **제약**: 개별 Agent Skills 라이선스, 고성능 모델 비용, 고객 코드 외부 전송 승인, 원본 Skill 단순 재판매 지양.

## 6. 권리·비용·출시 심사
1. **라이선스**: 저장소 LICENSE와 각 의존성/모델·폰트·영상·데이터의 재배포 조건을 실행 당일 확인. MIT/Apache/BSD도 고지 필요할 수 있음. AGPL 기반 Sure의 코드를 폐쇄형 원본처럼 전용하지 않는다. OpenMausBot enterprise 전용 폴더는 별도 권리 검토. 미확인은 판매용 코드에 도입하지 않는다.
2. **무료 제공**: 오프라인 기능과 외부 API/LLM 호출을 분리하고, 모델 파일 크기·GPU/CPU·고객 PC/Windows 설치·유지보수 비용을 따로 표시한다. '모든 기능 영구 무료' 보장 금지.
3. **실제 품질**: 사용 허가·개인정보·소스 보호·오류 복구·Windows 실행·설치/제거·실고객 검수. 금융 투자자문이나 안전 감지 등 고위험 결과를 확정 성능으로 판매하지 않는다.
4. **사업화**: 데모 1건→시나리오별 검증 시간·지원 시간 계측→고객 견적 범위 확정→판매 승인. GitHub 별 증가는 구매 의향 증명이 아니다.
